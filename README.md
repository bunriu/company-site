# くとー配信 コーポレートサイト

架空の動画配信会社「くとー配信」の1ページ企業/サービスサイトです。

## 概要

「編集部が本当に良いと思った作品だけを届ける」をコンセプトにした、動画配信サービスのランディングページです。以下のセクションで構成されています。

- ヘッダー / ナビゲーション
- お知らせ欄
- ヒーロー(キャッチコピー・CTA)
- サービス紹介
- 機能特徴
- 料金プラン
- 対応デバイス
- 会社概要
- フッター

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `kuto-haishin.html` | ブラウザで開く完成ファイル |
| `Main.dc.html` | ページ本体のデザインソース |
| `canvas.json` | デザインキャンバスのレイアウト定義 |

## ブラウザで開く手順

1. このリポジトリをローカルにクローンまたはダウンロードします。
2. `kuto-haishin.html` をダブルクリックして、既定のブラウザで開きます。
   - もしくはブラウザのアドレスバーに `kuto-haishin.html` のフルパスを入力してアクセスします(例: `file:///C:/ProjectL/company-site/kuto-haishin.html`)。
3. サーバー起動は不要です。ファイルを直接開くだけで表示されます。
